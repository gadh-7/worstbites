### Project Description

Worstbites is a fun food-discovery platform that helps users find and share the worst-rated, weirdest, and most questionable food experiences around them. Instead of searching for the best restaurants, Worstbites embraces the chaos and helps users discover places that probably should have stayed a secret.

### The Problem (that doesn't exist)

People have spent far too much time looking for highly-rated restaurants, beautiful food photography, and five-star reviews.

But what about the restaurants that serve suspicious-looking food, have questionable reviews, or somehow manage to turn a simple meal into an unforgettable disaster?

**Nobody was solving this extremely important problem.**

### The Solution

Worstbites flips the traditional food-discovery experience upside down.

Instead of recommending the *best* places to eat, Worstbites helps users discover the **worst bites** — questionable restaurants, terrible food experiences, hilarious reviews, and places that deserve a little roasting.

Users can explore food spots, check out their reputation, and enjoy entertaining commentary about why a particular place might not be their best life decision.

Because sometimes a **1-star experience is a 5-star story.**

## Technical Details

### Technologies/Components Used

For Software:

* **Languages:** JavaScript / TypeScript
* **Framework:** Next.js
* **Runtime:** Node.js
* **Styling:** CSS / Tailwind CSS
* **Libraries:** React and supporting npm packages
* **Version Control:** Git and GitHub
* **Deployment:** Vercel
* **Location/Data Services:** Free/open alternatives instead of Google Maps API
* **Development Tools:** Visual Studio Code, npm

### Implementation

For Software:

Worstbites is implemented as a web application using Next.js and React.

The application provides a user-friendly interface for discovering questionable food spots and presenting their information in an entertaining way. The project combines location-based information with humorous descriptions and roasting-style commentary to create a food-discovery experience that is intentionally different from conventional restaurant platforms.

The application was designed to avoid dependence on paid Google Maps services and instead uses free alternatives wherever possible.

# Installation

Clone the repository and navigate into the project directory:

```bash
git clone https://github.com/gadh-7/worstbites.git
cd worstbites
```

Install the required dependencies:

```bash
npm install
```

Create the required environment configuration file if the project uses environment variables:

```bash
.env.local
```

Add the required API/configuration values to `.env.local`.

# Run

Start the development server:

```bash
npm run dev
```

The application will normally be available at:

```text
http://localhost:3000
```

### Project Documentation

Software:

Worstbites is a web-based food discovery application designed around the concept of finding the **worst food experiences instead of the best ones**.

The project focuses on turning negative restaurant experiences into entertainment. Rather than simply displaying conventional ratings, the platform presents questionable food spots through humorous content and roasting-style commentary.

The main workflow of the application is:

1. User opens the Worstbites web application.
2. User explores available food locations.
3. The application retrieves relevant location/restaurant information using free services.
4. Restaurants and food spots are presented with their available information.
5. Users can discover questionable places and read humorous commentary.
6. The overall experience encourages users to explore the lighter and more ridiculous side of restaurant reviews.

The project demonstrates the use of modern web development technologies including **Next.js, React, JavaScript/TypeScript, npm, Git, and Vercel**, while avoiding reliance on paid Google Maps APIs.
